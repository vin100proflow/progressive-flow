# Security Policy

## Supported Versions

The following table outlines the versions of Progressive Flow currently supported with security updates:

| Version | Supported          |
|---------|--------------------|
| 1.x     | ✅ Yes             |
| < 1.x   | ❌ No              |

If you're using an unsupported version, please consider upgrading to the latest release.

## Reporting a Vulnerability

We take security vulnerabilities seriously and appreciate your efforts to responsibly disclose any issues.

### To report a vulnerability:
1. **Contact:** Please email us at `vincent.legnani.biz+security@gmail.com` with the details of the vulnerability.
2. **Include:**
   - A detailed description of the issue.
   - Steps to reproduce the vulnerability.
   - The potential impact on users or systems.
   - Any suggested fixes or workarounds, if available.

### Response Timeline

- We will acknowledge receipt of your report within **48 hours**.
- A preliminary assessment and proposed timeline for resolution will be provided within **7 days**.
- Critical vulnerabilities will be prioritized, and fixes or mitigations will be released as soon as possible.

## Best Practices for Contributors

If you are contributing code to Progressive Flow:
- Ensure that your code adheres to best practices for security.
- Avoid introducing hard-coded secrets or credentials.
- Validate and sanitize all user inputs.
- Notify the maintainer immediately if you notice a potential security risk during development.

Thank you for helping to keep Progressive Flow secure!
