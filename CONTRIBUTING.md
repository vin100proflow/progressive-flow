# Contributing to Progressive Flow

Thank you for your interest in contributing to Progressive Flow! Here are the guidelines to ensure a smooth collaboration and maintain the security and integrity of the project.

## Development Workflow

- **Work on the `develop` branch**: All changes must be based on the `develop` branch, which serves as the staging area for ongoing development.
- **Pull Requests (PRs)**: Submit your contributions via a pull request. This allows for code review and ensures that the changes align with the project’s goals and standards. For security and integrity reasons, pull requests will only be merged after a thorough review.

## Getting Started

This project is a straightforward Bash script, making it easy for anyone to contribute. Here’s how you can get started:

1. Clone the repository:
   ```bash
   git clone https://github.com/vin100proflow/progressive-flow.git
   ```

2. Navigate to the project directory:
   ```bash
   cd progressive-flow
   ```

3. Connect your local repository to the remote `develop` branch:
   ```bash
   git checkout develop
   ```

4. Make your changes locally and push them to a new branch:
   ```bash
   git checkout -b your-feature-branch
   ```

## Submitting Your Contribution

1. Push your changes to your forked repository:
   ```bash
   git push origin your-feature-branch
   ```

2. Open a pull request to the `develop` branch of this repository.

## Additional Notes

- **Code Style**: Since this is a Bash script, focus on writing clean, readable, and well-commented code.
- **Testing**: Ensure your changes are tested and do not break existing functionality.

We appreciate your contributions and are excited to collaborate with you to improve Progressive Flow. If you have any questions, feel free to open an issue in the repository.

Happy coding!
